OpenLP for macOS

Choose the build that matches your Mac's processor. These packages are from the same OpenLP source revision and are provided as unsigned preview builds.

Important: preview builds, not signed or notarized

These application packages are currently unsigned and have not been notarized by Apple. macOS may warn you or prevent the app from opening.

Neither package has yet been smoke-tested on a physical Intel or Apple Silicon Mac. Do not disable Gatekeeper globally or bypass macOS security protections to install this build. For general/public production use, wait for a signed and notarized release.

Installation

  1. Confirm your Mac's processor type, then download the matching DMG above.
  2. Open the downloaded DMG file.
  3. Drag OpenLP.app into your Applications folder.
  4. If replacing an existing installation, quit OpenLP first. Review the macOS security warning above before attempting to launch this unsigned preview.

Protect your existing OpenLP data

These downloads are application bundles, not database migration tools. The intended installation is to replace the application in Applications while leaving your OpenLP user-data folder in place.

Back up your OpenLP data before replacing an existing installation. Preservation of the Custom Slides database and index has not yet been verified on a physical Mac. Do not treat this preview as confirmation that a production database migration or backup is unnecessary.
